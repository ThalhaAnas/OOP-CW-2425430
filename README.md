# TeamMate Intelligent Team Formation System

## Overview
A Java-based intelligent team formation system developed for a university gaming club. The system automatically creates balanced teams using personality traits, skill levels, preferred roles, and gaming interests.

## Features
- Player survey system
- Personality classification
- Team balancing algorithm
- CSV file import/export
- Exception handling
- Multithreading support
- UML-based software design

## Functionalities

### Survey System
Collects:
- Personality scores
- Skill levels
- Preferred gaming roles
- Game interests

### Team Generation
Creates balanced teams by considering:
- Personality diversity
- Role variety
- Skill distribution
- Gaming preferences

### File Handling
- Load participant data from CSV
- Save generated teams to CSV

## Exception Handling
The system validates:
- Invalid personality scores
- Incorrect roles
- File reading/writing errors
- Missing inputs

## Concurrency Features
Threads are used for:
- Processing survey data
- Parallel team generation
